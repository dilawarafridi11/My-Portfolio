## ✨ Features

- **Hero** — animated entrance, typing effect, orbiting tech chips, canvas particle background with gradient blobs and code symbols
- **About** — bio, tech stack and animated counters with progress bars
- **Skills** — four animated cards (Frontend, Mobile, Tools, Software Engineering) with progress animations and tag pills
- **Projects** — six projects with category filtering (All / Web / Mobile / Desktop / Software Systems), hover effects and a detail modal
- **Experience** — animated vertical timeline
- **Education** — Sarhad University, BS Software Engineering with coursework
- **Services** — four service cards with animated icons
- **Why Work With Me** — four value cards
- **Contact** — contact details, social links and a validated contact form (Vanilla JS frontend validation)
- **Extras** — sticky glass navbar with active-link detection and mobile hamburger menu, scroll-to-top, preloader, scroll-reveal animations, smooth scrolling, keyboard/Escape support, `prefers-reduced-motion` support

## 🎨 Design

- Dark navy background with blue / cyan / purple gradient accents
- Glassmorphism cards, soft shadows, rounded corners
- Fully responsive breakpoints: 320px → 1440px+
- No horizontal overflow

## 🔧 Customization

- Update social URLs (`https://github.com/`, etc.) in `index.html` and the `PROJECTS` data in `js/script.js`
- Replace the illustration or add real screenshots inside `images/`
